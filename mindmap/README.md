# Mind-map Viewer

This folder contains a browser-based interactive viewer for your dissertation argument graph.

## Quick start (local)

From the repository root:

```bash
python3 scripts/build_argument_graph.py
scripts/run_mindmap.sh
```

Then open:

- `http://localhost:8000/mindmap/`

## Use a different port

```bash
scripts/run_mindmap.sh 8080
```

Then open:

- `http://localhost:8080/mindmap/`

## Manual alternative

If you prefer, you can run a server directly:

```bash
python3 -m http.server 8000
```

and open `http://localhost:8000/mindmap/`.

## Controls

- Click any node to focus it.
- **Back to Thesis Root**: return to top-level map.
- **Up One Level**: navigate to parent argument node.
- Side panel shows:
  - child nodes
  - cited sources linked from the focused node
  - breadcrumb path

## Data source

The UI reads `mindmap/argument_graph.json`, generated by:

```bash
python3 scripts/build_argument_graph.py
```
