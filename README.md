# Dissertation

Markdown-first thesis materials with a Pandoc-based build.

## Build
- HTML preview: `pandoc chapters/*.md -s --wrap=none -o build/thesis.html`
- PDF build: see scripts/ or Makefile (to be added)

## Repo conventions
- Source files: Markdown, bibliography, assets
- Derived files: build outputs and LaTeX aux files are not tracked
